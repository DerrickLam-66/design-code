# Cline 全局强制规则（通用高效版）
## 1. 语言强制约束
- 全程**只使用中文**沟通、回复、解释、报错说明、代码注释。
- 禁止任何英文自言自语、禁止中英夹杂闲聊。
- 所有总结、步骤、反馈、结果全部用简洁中文输出。

## 2. 禁止无限循环 & 禁止重复废话
- 任务分析完成、执行完成后**立刻终止对话**，禁止反复复述、重复总结、循环自问自答。
- 同一内容禁止多次重复输出，不要额外延伸无关话题。
- 得到确定结果后只简洁告知：任务已完成，不再追加多余分析。
- 禁止主动发散、禁止自动续写无关内容。

## 3. 工具调用强制规范
- 涉及创建文件、修改文件、运行命令、读取文件，**必须使用官方工具**：write_file / read_file / run_command / list_directory 等。
- 禁止只口头描述步骤、不实际创建/修改文件。
- 能工具操作绝不只用文字敷衍说“已完成”。
- 操作前先确认路径，不随意乱建文件夹、不乱生成冗余文件。

## 4. 代码编写规范
- 生成代码结构清晰、缩进标准、自带必要中文注释。
- 遵循现有项目目录结构，不擅自更改已有配置文件。
- 禁止随意删除项目文件、修改核心配置、篡改已有业务逻辑。
- 生成后自动遵循 ESLint / Prettier 格式规范。

## 5. Figma MCP 专用规则
- 对接 Figma MCP 时，只读取设计稿信息，不擅自修改 Figma 资源。
- 解析 Figma 页面、组件、色值、尺寸、字体后，**只输出一次整理结果**，不反复轮询重复解析。
- 按设计稿 1:1 还原样式，不私自改色值、尺寸、圆角。
- 解析完成直接给出结构化中文总结，立刻停止，不循环刷新连接。

## 6. Git 集成规范
- 允许正常查看 git status、提交代码、查看日志。
- 自动提交格式统一：`feat: 生成/更新 组件名/页面名`
- 禁止强行改写 Git 历史、强制推送、乱合并分支。
- 重大文件变更前主动提示用户确认再执行。

## 7. 交互简洁高效规则
- 回答精简直击重点，不长篇废话、不堆砌客套话。
- 报错直接给出原因 + 可直接复制的解决命令，不绕弯。
- 看不懂指令只简洁提问一次，不反复追问。
- 多步骤任务拆成清晰分步，每步做完给简短反馈。

## 8. 本地 Ollama 适配规则
- 适配本地 Ollama 模型输出特点，控制生成长度，不无限续写。
- 严格遵守用户给定指令范围，不擅自扩展需求。
- 不主动切换模型、不擅自修改 Temperature 等参数配置。
